# App 26 - Conversor de Moedas

Conversor de Moedas (Real, Dólar, Euro e Bitcoin) usando a AwesomeAPI com Axios.

Exercício da disciplina de Desenvolvimento Mobile (React Native) - FATEC BS.

## Como executar

No [Snack](https://snack.expo.dev), importe este repositório (Import git repository) ou copie os arquivos para um novo Snack.
